# NL形式NCの照合（2026-10-21）

所有者提供のNL2000対話NC 5本を、出力書式・モード・工程構成の参考として確認した。
加工寸法は下記の独立した解析作例と照合する。元NCの加工形状を再現した比較ではない。
提供ファイル、プログラム名、加工寸法、工具CAD、生成したNCやスクリーンショットは公開しない。

## 解析作例の確認結果

共通の素材外径は40 mm、素材前端Zは+1 mm、接近面はZ+3 mm、チャック前面はZ-45 mm。
旋削の仕上げ代は片側0.1 mm・Z方向0.1 mm。値は検証用で、実機加工条件の推奨ではない。

| 作例 | 確認した寸法・経路 | 結果 |
| --- | --- | --- |
| 段付き外径 | 仕上がりφ30／φ36、肩Z-12、奥Z-30。荒輪郭はφ30.2／φ36.2・肩Z-11.9、奥端まで荒取り。端面荒はZ+0.1、仕上げはZ0 | 一致。T1212→T0606、G96、F0.1→F0.06。52移動 |
| 段付き内径 | 下穴φ10、仕上がりφ20／φ16、肩Z-10、奥Z-30。荒輪郭はφ19.8／φ15.8・肩Z-9.9 | 一致。T0505→T0707。軸方向の早送りは下穴内のφ6。42移動 |
| センター＋ドリル | φ3センター先端Z-2、φ8ドリル先端Z-25、4 mm刻み。穴加工中はX0、各切削後にZ+3へ全退避 | 一致。T0101→T0202、G97 S1000、F0.04／F0.08。17移動 |
| 外径溝の荒／仕上げ | 前壁Z-8、幅4、底φ24、工具幅2。荒底φ24.2、両壁に0.1。仕上げの工具前側刃先Zは-8〜-10、工具の後端がZ-12に到達 | 一致。T1111→T0808、G97 S700、F0.06。79移動 |

ドリルのZは先端位置。118度のφ8ドリルでは、先端Z-25で指定径になる最深位置は約Z-22.597。
指定径の穴がZ-25まで開く意味ではない。

外径・内径は解析モデルから輪郭を再取得し、設計保存→再読込→工具経路→NCをCLIで実行した。
穴・溝は解析モデルを表示し、明示した加工寸法から出力した。穴・溝の自動輪郭抽出を確認したものではない。

出力NCのG0/G1を計算器のフェーズ・工程範囲とは別に読み取り、工具、S/F、各切削線分の
端点・中間点、肩の取り代、溝の工具幅、加工中の接近・退避を解析寸法と比較した。
外径の軸方向早送りは素材外のφ44、内径は下穴内のφ6、穴はX0でZ+3までの退避を確認した。
これは名目刃先の経路検査であり、実工具・ホルダーの干渉判定ではない。

再現テストは既存の `crates/cam/src/post/tests.rs` の `exported_*` 4件。

```text
cargo test --profile ci -p solidcraft-cam --lib post::tests
```

## 今回のCI修正

`new_cards_settle_before_the_first_click_in_both_layouts` の回転体作例は、XY面の輪郭に
面法線のZ軸を指定していた。プレビューが失敗し、そのエラー表示の非同期到着が
フッターを動かすため、GitHubの負荷・実行タイミングによって失敗していた。

作例を面内のY軸に修正し、同じテスト内で実際の形状生成も確認する。
初回フッター位置の比較は保持する。待ちフレームの追加やテストの無効化は行わない。
関連ダイアログ75件がローカルで通過した。GitHubの結果はPRの最新検査を参照。
