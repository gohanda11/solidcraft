# 旋盤CAM：方針と実装状況

ユーザーとの設計相談で合意した旋削 CAM の開発方針と実装状況。
本家の CAM ロードマップとは独立した機能開発です。
開発先は [gohanda11/solidcraft](https://github.com/gohanda11/solidcraft)、
ブランチは `cam/turning-foundation`。2026-10-23 に本家 `edf57cec`（0.20.0 と、その後の更新）へ統合し、
2026-10-25 に `16286249`（0.22.0 と、その後の更新）へ更新しました。
`main` は本家の比較基準として維持します。[更新・差分管理の手順](cam-fork-workflow.md) を参照してください。
以下の過去の検証記録にある「未コミット」「未統合」は当時の状態です。

## 対象と操作

- SolidCraftを拡張し、同じアプリ内に旋盤CAMを追加する。Rustと既存のegui画面を利用。
- SolidCraftで作成したモデル、または支給されたSTEPモデルを使用する。
- 最初の対象機はNL2500。後からSL25用の出力設定を追加できる構成にする。
- 対象はX・Zの旋削。回転工具、C軸・Y軸加工は今回の対象外。
- 主な製品は外径Φ100以下、長さ100mm程度。素材には加工代があるため、この値を素材の上限にしない。
- 材質はS45C、SUS303、SUS304、HPM1、樹脂、真鍮、銅など。初期の切削条件を推測して固定しない。
- 人が工具、加工輪郭、範囲、工程順、切削条件を指定する。
- 3Dで製品を確認し、回転軸に対するX–Z輪郭上で加工対象を選択する。
- ①②は輪郭と段階別の設定、③は工具・輪郭・工程、④は工程・2D再生・NCを表示する。

### 現在の操作順（2026-10-25：2Dの4段階）

CAMはCADと共通のコントロール・テーマを使います。通常のCAM画面は常に横向き2Dで、
画面のパン・ズームはCADと同じナビゲーション設定です。CAMのカメラはCADのカメラを変更しません。

1. **① 輪郭・加工方向**：モデルが1つなら中心軸と断面を自動抽出。
   外径→背面端面→内径（穴がない部分は中心軸）→正面端面の閉じた輪郭を表示します。
   最初に加工する側が右です。「加工方向を反転」で逆側を右にできます。
   複数モデルでは対象を選択。再抽出は外径・内径を1回のUndoでまとめて更新します。
   線をダブルクリックすると、その線の公差・ねじピッチ・中点分割を編集できます。
   全長・最大径・Z0を図上で確認でき、「全体表示」でパン／ズームを戻せます。
   公差は寸法情報であり、NCの狙い寸法を自動補正しません。ねじ指定がある間は
   未対応のねじを円筒として誤出力しないように経路とNCを停止します。
   止まり穴は断面表示と指定径・先端角・深さによるドリル加工に対応します。
   内径バイトによる輪郭加工は連続した貫通穴のみです。穴のないモデルへの穴追加、
   指定ドリルによる完成側面・穴底への削り込みは拒否します。
   CAD更新時は止まり穴の深さや中実部分も再照合し、古い輪郭での計算を停止します。
2. **② 材料・削る部分**：素材径／長さ、前面Z、チャック前面Z、退避、材質の順に設定。
   橙で材料と形状の差分、青で完成形状、灰で背面の残材、赤で材料不足を表示します。
   外径・下穴・材料前後端の不足箇所とZ範囲を示し、不足がある経路作成は拒否します。
   検査対象は既知の完成輪郭です。内側輪郭が未設定の手入力データでは、完成内径に対する
   材料不足を確認できません。
   検査は保存された折線輪郭と材料の交点から計算し、シミュレーションの分解能に依存しません。
   モデルのRは材料側への最大0.001 mmの近似を含むため、その近傍は保守的な判定です。
   材料不足の検査と加工後の残材表示は別です。残材は断面近似で、止まり穴の未加工部分も含みます。
   「材料不足なし」は仕上げ代・工具進入・干渉まで保証する判定ではありません。
   材料や退避が未設定の場合は「次へ」を無効にし、修正する項目を表示します。
   輪郭を設定した段取りでは、この配置を穴・溝工程にも使います。保存された外径・内径の
   共通配置が不一致なら計算を拒否します。製品後端がチャック領域内でも部分加工は設定でき、
   実際に指定した加工範囲で退避境界を検査します。
   材質別の3段階の条件候補は
   「適用」を押すまで既存条件を変えません。ここでは工具・工程一覧を表示しません。
   終了方針は「つかんだまま／裏返して加工／突っ切り仕上げ→手動分離／突っ切り」。
   裏返し・突っ切り系は方針の保存までで、経路は未対応です。選択されている場合は
   未完了のプログラムを完成NCとして出力しません。
3. **③ 加工工程**：左にT01〜T12、中央に輪郭、右に工程と選択範囲の条件を表示。
   工具を選び、外径／内径の線区間または輪郭点2つで加工範囲を指定します。分割点も選べます。
   通常は点の密集を抑え、詳細点の表示やズームで元の全点を選べます。計算用の輪郭は間引きません。
   選択範囲と始点／終点を強調し、経路確認では今回追加する工程と本数を表示します。
   既存工程の経路は切り替えて重ねられます。
   正の取り代なら荒取り、片側・Zの両方0なら仕上げを提案。
   仕上げ前の残材が多ければ荒＋仕上げを提案し、確認後に追加します。
   自動追加する荒取りは②で設定した外径／内径の荒条件を使い、仕上げの送り・上限と区別します。
   候補ごとに使用工具・取り代・切込み・送りを確認できます。
   荒取り候補は片側0.1 mm・Z方向0.1 mm。モデル・方向・点の分割が変わった
   既存の範囲工程は再指定が必要です。工程を選んで「この工程の範囲を変更」から更新します。
   工具・種類・名前・条件・順序を保持し、工程数は増やしません。通常は更新後の全経路を
   確認して置き換えます。複数工程の再選択が必要なら「範囲のみ保存（経路未計算）」で
   1件ずつ修復できます。どちらもUndo対象で、NC確認前に全体を再計算します。
   穴・外径溝・端面は工程追加から寸法を指定します。
   穴・溝工具を選ぶと、その工具と種類を設定した追加確認を開きます。種類変更と追加の詳細は
   折りたたみ、追加操作を先に表示します。「追加して設定へ」で工程を追加し、寸法を入力します。
   両側が同径の矩形外径溝では、通常旋削用の経路だけ両側の外径をつなぎます。
   完成輪郭には溝を残し、壁・底を別の溝荒／仕上げ工程で加工します。
   モデル連動の溝は前端・幅・底径の一致が必要です。溝壁・底で終わる通常旋削の
   部分選択、斜面・R付き溝は未対応です。モデルなしの手入力穴・溝は指定寸法を完成意図とし、
   CAD形状との一致を検証していないことを表示します。
   工具をダブルクリックすると役割・型番・補正・チップ・ホルダーを編集できます。
   空き工具もダブルクリックで登録できます。
   工具選択だけでは重い差分計算を実行せず、経路確認を押したときに計算します。
4. **④ シミュレーション・NC**：左に工程と干渉結果、中央に2D残材再生、右にGコード。
   シミュレーションを計算すると同じリビジョンの確認用NCも生成します。
   工程をクリックすると、除去前の材料を保ちながら、その工程の工具と先頭NC行へ移ります。
   NCは行番号と現在行を表示し、再生位置へ追従します。NCの移動行をクリックして再生位置へ戻ることもできます。
   出力に含まれない工程間移動は別の行へ誤対応させず、その旨を表示します。
   チップのR付き輪郭、寸法・配置を確認済みのホルダー包絡、チャック前面・残材に対する
   既存の連続移動の干渉計算を使い、候補があれば再生を止めて赤で示します。
   ホルダーのSTEP登録だけでは、この干渉包絡の設定・確認にはなりません。
   停止時には接触候補の動作番号・工具・理由・座標と、接触前に完了した動作数を表示します。
   初期表示範囲には工具・ホルダーの移動範囲も含めます。
   ドリル・溝工具は指定径／先端角／幅による名目形状を描画し、早送りの残材接触候補を検出します。
   完成輪郭がある場合は削り込み候補も検出します。モデルの頂点を断面分割に含め、細い矩形形状を保持します。
   加工終端を短くしても検査には全体の完成輪郭を使い、経路外の肩へ張り出すチップの接触候補も確認します。
   軸方向の断面近似であり、実フルート、溝工具の高さ、取付姿勢を含む連続3D検証ではありません。
   完成輪郭のない穴・溝だけの計画も材料と経路を表示し、完成輪郭は未設定と明示します。
   寸法未確認のホルダー、名目刃先のみの工具、未検査移動を別表示します。
   「出力設定」でNL形式、X正負、S値などを変更できます。変更後の古いNCと再生は無効です。

「CAMをリセット」は工程・輪郭・材料・プレビューを消して①へ戻します。
最初の段取りの工具、出力設定、材質と工具CADライブラリーを保持し、Undoで復元できます。
モデル本体は変更しません。

通常旋削で到達できない溝底・裏向き面の自由なチェーン加工、刃先R補正後の実機経路、
機械全体の干渉保証は未対応です。2D表示は登録した干渉包絡の検査を置き換えません。
未確認工具がある結果を「干渉なし」とは表示しません。NCは先頭M30を保持する確認用です。
内径進入では先行ドリルの先端深さと全径深さを区別します。
[NL出力設定](turning-nl-post.md) と [NC照合記録](turning-nc-audit.md) も参照してください。

追加コマンド：`cam.turning.difference`、`cam.turning.selection.preview`、
`cam.turning.selection.add`、`cam.turning.selection.update.preview`、
`cam.turning.selection.update`。追加・通常更新はリビジョン検証・再計算を行ってから
一括保存し、Undo対象。明示的な`range_only:true`の更新だけは経路未計算の下書き保存です。

## 標準タレット

| 番号 | 用途 |
|---|---|
| 1 | センター |
| 2 | ドリル |
| 3、4 | 空き |
| 5 | 内径荒 |
| 6 | 外径仕上げ |

各段取りに独立した配置のコピーを保存する。保存済み案件を標準配置の変更で上書きしない。

メーカー寸法候補、利用者が取得したSTEP、R付きチップ形状に対応する。機械全体の取付は未検証。

## 段取りと工程

段取りはつかみ直しの単位。段取り内に任意の加工工程を順に並べる。
表加工後の裏返し、棒材からの突っ切り、突っ切り仕上げを扱う。
外径・内径・端面の荒加工／仕上げ、穴、外内径端面溝、外内径ねじを順次実装する。

「突っ切り仕上げ」は、とがった刃先の工具で裏側の端面・輪郭を仕上げ、内径と同じ径まで
削った後に人が軽く叩いて分離する作業を指す。NC加工終了と手動分離完了を区別する。
薄皮の厚みや実工具形状はまだ未確認。自動的に推定しない。

- `part_off`：通常の切離しを予定する工程。
- `parting_finish`：仕上げ後の手動分離を予定する工程。
- 後者は仕上がり内径と終了径を必須とし、最初の終了径候補は仕上がり内径と同じにする。
- 仕上がり内径は分離位置の加工後寸法。素材の穴径とは異なる。
- 現在はその寸法を明示入力する。将来は先行する内径工程と参照・更新関係を持たせる。
- 切離し／手動分離工程は段取りの末尾に置く。その後の加工は別段取りにする。
- 段取り間の参照は、前にある段取りだけを指せる。現時点では素材の受渡し計算や反転は行わない。

## 端面・外径の経路と取り代

右側の「経路」で手入力輪郭を設定する。各行は `Z 直径`（mm）。仕上がり端面をZ0、
チャック側を負のZとする。Zが減るにつれて径が同じか大きくなる直線・段付き・テーパーに限定。
端面荒→外径荒→端面仕上げ→外径仕上げの工程順だけを受け付ける。仕上げ無効時は荒2工程のみ。
旧`face`は読込可能だが、経路計算前に荒・仕上げを明示して分ける。内径、溝、ねじ、切離し、
前段取りからの素材引継ぎがある計画は、一部を黙って省略せず計算を拒否する。

- 素材端面Z、チャック前面Z、逃げ量、片側・Z方向の仕上げ代、切込み、送りを明示設定する。
  仕上げ代の初期値はユーザー指定の外径片側0.1mm、Z方向0.1mm。切込み・送り等のゼロは未設定。
  材質から切削条件を推定しない。既存文書の保存済み取り代は初期値変更で上書きしない。
- 荒輪郭はX直径に片側取り代の2倍、Zに端面取り代を加算する。
  最後のZは製品の加工終端まで延長し、奥側に未加工リングを残さない。
- 荒取り後に荒輪郭をなぞり、層状切込みの段残りを除く。その後、指定時のみ端面・外径を仕上げる。
- 早送りは必ず1軸ずつ。切削後は送りで手前へ逃げてからXを外へ、Zを素材前方へ退避する。
- 素材不足、加工範囲外、チャック前面＋逃げへの進入、逆向き輪郭、過剰な点数・パス数を拒否する。
- 取り代表は肩の両側・Z取り代の狭い帯・区間中点を含む。円筒の片側0.2mmは直径差0.4mm。
  テーパーはZ取り代も径差へ影響する。肩直前の大きな径差は、Z方向に残る肩の材料を含む。
  表の径差だけを工具の実切込みや負荷と解釈しない。
- 体積は円筒・円錐台の解析積分。仮想刃先の送り線を仕上がり輪郭の各直線区間と照合する。
  テストでは別方式で先行経路から残素材を再構成し、早送りと残素材、荒・仕上がり径を検証する。
- 画面の灰色＝素材、黄＝荒輪郭、青＝製品断面。スライダーは経路の表示範囲を変える。
  色面は計画断面であり、削られていく素材のシミュレーションではない。

`examples/turning-toolpath.json` はΦ60素材からΦ20/40/50、加工長60mmの段付き軸を作る確認例。
片側0.1mm・Z方向0.1mm、素材端面Z2、チャック前面Z-70。送り・切込みは試験値で、実加工推奨値ではない。
CADサンプルと手入力輪郭は同じ寸法で作ったが、自動的な対応関係はない。

## 確認用NC

G00/G01の展開座標を `.nc` に書き出す。**実機投入用ではない。** 冒頭のM30で動作行を実行しない形にしてあり、
工具交換・補正・主軸・原点・送りモードを推測して埋めない。確認用の仮想刃先座標なので、
M30を削除するだけでは実機用にならない。実機ポストと工具幾何の追加が必要。

アプリでは「経路」→「経路計算・取り代確認」→「Gコードを表示」で読める。
「Gコードをコピー」と「確認用NCを書き出す」も使用可能。画面の表示とファイル出力は同じ
`cam.turning.nc` コマンドで生成し、条件変更後は旧コードを表示・出力しない。
長いNCでも表示範囲の行だけレイアウトし、スクロール時に全行を描画しない。

出力時に経路を再計算し、文書revisionと確認済みrevisionの一致を要求する。X・Zを素材外側へ
0.0001mmで丸め、丸め後も食込み検査を行う。既存ファイルの上書きは明示指定が必要。
G71やG70等の固定サイクル出力は未実装。

ユーザーの制御装置の記憶は「MAPPSかもしれない」。コード体系・工具呼出しは未確定。
参考として公式 [Haas G71](https://www.haascnc.com/service/codes-settings.type%3Dgcode.machine%3Dlathe.value%3DG71.html) は
仕上げ代Uを直径、切込みDを半径として区別するが、これはNL2500の仕様を証明するものではない。
[三菱電機の旋盤系プログラミング説明書](https://app.mitsubishielectric.com/dl/fa/document/manual/cnc/bnp-b2264%28eng%29/bnp-b2264%28eng%29d.pdf)

## コマンド

画面は左上のワークスペース選択から「旋削CAM」を開き、「NL2500の工程計画を作成」で開始。
有効な編集は即座に文書へ反映され、通常の保存とUndoが使える。不正な変更は反映せずエラーを表示。
新しい素材寸法は「適用」を押して確定する。補正番号の0は未設定を示す。
工程名・機械名を空にする変更は拒否されるため、全選択して新しい名前を入力する。
素材や工具の未設定を許す計画画面。実機用NCボタンは無効で、経路タブに確認用NCの出力ボタンを分ける。
`ui.workspace {"workspace":"turning"}` で自動操作からも同じ画面を開ける。

- `cam.turning.defaults {}`：NL2500の計画テンプレートを返す。文書は変更しない。
- `cam.turning.get {}`：現在の計画、各段取りの予定状態、NC出力不可を返す。
- `cam.turning.set {"plan": ...}`：計画全体を検証して置換する。変更は一つのUndo。
- `cam.turning.set {"plan": null}`：計画を削除する。Undoで復元可能。
- `cam.turning.toolpath {"setup":"setup-1"}`：経路と取り代表、確認時のrevisionを返す。文書は変更しない。
- `cam.turning.nc {"setup":"setup-1","expected_revision":123,"path":"review.nc"}`：確認用断片を保存。
  revisionはtoolpathの戻り値を使う。path省略なら文字列を返すだけ。`overwrite:true`は明示的な上書き指定。

未知のフィールドはエラーにする。`set`でplanキーを省略した場合もエラーにし、削除とは扱わない。
テンプレートでは素材、実工具名、補正番号を未設定にする。
`examples/turning-plan.json`は手動分離を含む計画だけの実行例。NCプログラムではない。
`examples/turning-workspace.json`は外径最大56mm、長さ70mm、内径20mmの段付き中空軸と
工程計画を作る画面確認用サンプル。素材は外径60mm、長さ80mm。モデルと工程の自動関連はまだない。
公式制御APIの `engine.script` で実行し、`ui.workspace {"workspace":"turning"}` で開く。

```text
cargo test -p solidcraft-cam
cargo test -p solidcraft-engine --lib cmd::cam::tests
cargo test -p solidcraft-ui-egui --lib turning_workspace::tests
cargo run -p solidcraft-cli -- run examples/turning-plan.json --out target/turning-plan.solidcraft
```

## 穴あけ・外径溝の荒／仕上げ（2026-10-18）

工程追加の「穴あけ」からセンター／ドリル、「溝・ねじ」から外径溝荒／外径溝仕上げを選ぶ。追加後、右側にその工程専用の寸法・送り欄が出る。既存のセンター／ドリル工程は「加工寸法を設定」で設定を開始する。外径溝仕上げは先行する荒取りの寸法をコピーできる。T01/T02/T11/T08は標準タレットからの提案で、変更可能。

- ドリルはX0の軸方向加工。径、先端到達Z、先端角、1回の深さ、送りを指定する。1回の深さ0は一発、正の値は毎回素材前方まで全戻しするG00/G01経路。円すい先端＋円筒の近似であり、センタードリルの段付きパイロット形状は未対応。
- 到達Zは先端基準。指定径の到達位置は先端Z + 径/2/tan(先端角/2)。後続の内径荒取りには、その位置が内径輪郭の奥まで届く先行ドリル、または素材の既存下穴が必要。素材の下穴径を変更して穴あけ前の素材まで空洞にすることはない。
- 外径溝は矩形断面。手前壁Z、溝幅、底径、刃幅、径方向切込み、送りを指定する。工具のZ基準は手前側刃先、刃は負Z側に伸びる。荒取りは底に径方向0.1mm（径差0.2mm）、両側壁それぞれに0.1mmを残す既定値。幅を刃幅以下の重なり付き突込みに分割し、径方向にも分割する。仕上げは同じ溝寸法・取り代の先行荒取りが必須で、底と両側壁を仕上げる。刃先R補正は未対応。
- 端面・外径荒→センター／ドリル→内径荒→溝荒→各仕上げなど、一覧の順で計算する。荒取り・穴あけを仕上げより後に置く順序、刃幅不足／過大、重なる異なる溝、チャック域、下穴不足、過大なパス数を拒否する。端面・外径・内径の輪郭工程は従来どおり各1つ。
- 3D残材再生はドリル円すい／円筒と溝刃幅を使う軸方向中点スライス近似。新しい工具に三角チップを代用しない。工具表示は近似形状の線画。実ホルダー、フルート長、機械軸・工具交換の干渉認証は含まない。除去体積の従来集計には穴あけ・溝が入らないため、混合工程の画面では集計値を出さない。
- 確認用NCは保存した工程設定から再生成し、先頭M30で無効化したレビュー断片。G83や機械用工具呼出しを推測しない。突っ切り、ねじ、内径溝、端面溝の経路は引き続き未対応で、それらが工程表にある場合は全体のNC生成を止める。工程を黙って省略しない。
