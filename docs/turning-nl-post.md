# NL対話サンプルに基づくNC出力

所有者提供のNL2000実例5本で共通している書式を、旋削CAMの出力形式として追加した。
元のプログラム名・加工寸法・ファイルは公開リポジトリに含めない。
実例中の重複したN番号や連結行も雛形として複製せず、加工座標をCAMから再計算する。

## 操作

1. **⑤ Gコード → NC出力形式 → NL対話サンプル準拠（確認用）** を選ぶ。
   新しいNL2500段取りではこの形式が初期値。従来の設計は明示的に選ぶまで旧形式を維持する。
2. **NC座標・基本の回転条件** でO番号、Xの正負、G54〜G59、G50の回転上限、
   荒・仕上げの周速、穴・外径溝の固定回転数を設定する。
3. **工程ごとの回転条件** では、選んだ工程だけG96/G97・S値・回転上限を変更できる。
   送りF、切込み、取り代は加工工程の設定を使う。
4. **工具経路を計算 → Gコードを表示／保存**。設定変更後は再計算する。
   設定は設計に保存され、Undoに対応する。

機械名にはNL2500・NL2000などを選べる。名称と出力形式は別の設定であり、
NL2000の実例だけでNL2500の機械仕様まで確認済みとは扱わない。

## 書式と座標

各工程に一意なN番号とASCIIの加工種別コメントを付ける。
`G99G18 → G50S… → G54等 → G0T… → M8 → G96/G97 S… M3`、
再計算したX/Z移動とF、工程末のM9・M01、最後のM9・M5・M30という構成。
G96は通常旋削、G97はセンター・ドリル・外径溝の初期候補。
回転初期値は編集可能な実例の値で、材質・刃物に適した推奨条件という意味ではない。
G0/G1の展開経路を使い、U/W・G71・円弧命令への再構成は行わない。

内部のXは正の直径のまま、書出し時だけ符号を変える。材料差分・取り代・3D再生を変形させない。
全ての切削・退避移動が出力対象に含まれることを検査し、工具間の名目移動を実際の工具交換経路として流用しない。
旧輪郭形式で工程範囲がない場合も加工フェーズから割り当てる。除去する材料がない工程はコメントにする。

登録済みの工具補正番号を優先する。補正未登録時のT0101/T1212等は、
選択可能な「実例と同番号を仮使用」に基づく**確認用の仮定**で、NC中にも明記する。
実測した補正番号の登録状態は書き換えない。

## 未確認の機械指令

実例の `M86/M85` は他の機械での意味を推測しない。`G53 X0 Z0` の退避経路も未確認。
初期状態では両方とも実行行を出さずコメントにする。実例どおりの出力は画面で明示選択できる。
特定ワークで使われた大きなX/Z退避値を、他の設計へコピーしない。

全形式とも**全ての機械指令より前にM30を置く確認用NC**で、`machine_ready` はfalse。
刃先R補正、工具取付、工具交換前後の接近と機械退避、機械全体の干渉、制御装置の数値精度は未検証。
先頭M30の削除だけでは実機用にならない。座標精度は従来の工程付き確認用NCを継続する。
テストには公開できる解析形状を使い、提供NCの加工形状を複製しない。
